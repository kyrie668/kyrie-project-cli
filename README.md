# kyrie-project-cli

A CLI tool to build Vite projects with admin project template and visualization-screen template installed.

## Installation

You can install the CLI globally using npm:

```sh
npm install -g kyrie-project-cli
create-kyrie-project my-project
```

## Example:

```sh
create-kyrie-project my-project



cd my-project
npm install
npm run dev
```

# Features

- Vite
- ShadCN UI
- TypeScript
- Tailwind CSS
